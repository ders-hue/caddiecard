# CaddieCard

A phone-first, buildless app for one-off golf rounds. It supports:

- Smart club search with club-level favourites
- Course and tee selection backed by the UK Golf Course API
- Up to four players
- WHS Handicap Index to Course Handicap conversion
- Hole-by-hole stroke allocation using stroke index
- Individual Stableford scoring
- Temporary browser recovery only; finishing clears the round

Open `index.html` in a modern browser, or use the published GitHub Pages app.

The standalone `green-guide.html` page is the experimental Green Guide Lab. The repeatable course-vector extraction process is documented in `GREEN_VECTOR_WORKFLOW.md`.
